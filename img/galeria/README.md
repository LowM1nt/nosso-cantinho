# Galeria de Hello Kitty 🎀

Biblioteca de PNGs transparentes (fonte: [citypng.com](https://www.citypng.com) e [pngimg.com](https://pngimg.com) — uso pessoal).
Estas imagens **ainda não estão em uso** — é um acervo pra você escolher. Pra usar alguma, é só
apontar o `imgFb('img/galeria/<arquivo>', ...)` na tela desejada (mesmo padrão das imagens atuais).

## Sugestões por fase

| Arquivo | Sugestão de uso |
|---|---|
| `kitty-bolo.png` | Fase 1 — Receita Secreta (topo de bolo, com moldura redonda) |
| `kitty-bolo-rosa.png` | Fase 1 — alternativa de bolo/topper rosa |
| `kitty-bolsa-viagem.png` | Fase 2 — Mapa dos Encontros (Kitty com bolsinha, clima de passeio) |
| `kitty-lendo-livro.png` | Fase 3 — Quarto/detetive (Kitty lendo, combina com investigar) |
| `kitty-bailarina.png` | Fase 4 — Caixinha de Música (Kitty dançando bailarina) |
